# 订单查询

1. 买家说“查询我的当前订单”“查询我当前的所有订单”等，未提供订单号时先调用 `list_orders`，不要要求买家先找订单号。
2. `list_orders` 已绑定当前会话买家，不需要任何参数，不传买家姓名、买家 ID 或手机号。
3. 按返回数据列出订单号、商品、金额和状态；订单较多时逐条简洁展示，不把部分列表说成全部。
4. 返回零笔订单时告知“当前账号暂无订单”，不要编造订单，也不要因此创建转人工工单。
5. 买家给出具体订单号时使用 `get_order`；需要物流时使用 `get_logistics`。有多笔订单但买家未明确目标时，先列出订单再请买家选择。
6. 只有买家明确要求转人工或工具确实无法处理时才进入转人工流程，不因缺少订单号而转人工。
